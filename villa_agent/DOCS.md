# Villa Agent

Στέλνει στο Villa OS τις συσκευές του σπιτιού που ορίζει το αρχείο της βίλας. Δεν ανοίγει
καμία θύρα. Μόνο συνδέεται προς τα έξω.

## Εγκατάσταση (τοπικό add-on)

1. Στον υπολογιστή σου τρέξε `make addon`. Φτιάχνεται ο φάκελος `dist/addon/villa_agent`.
2. Αντέγραψέ τον στον φάκελο `addons` του Home Assistant, μέσω του add-on «Samba share».
   Η διαδρομή πρέπει να γίνει `\\homeassistant\addons\villa_agent`.
3. Πήγαινε Ρυθμίσεις → Πρόσθετα → Κατάστημα → ⋮ → «Έλεγχος για ενημερώσεις».
   Στα «Τοπικά πρόσθετα» εμφανίζεται το **Villa Agent**. Πάτα Εγκατάσταση.
4. Βάλε το αρχείο της βίλας στο `/config/villa_os/<site_id>.yaml`, μέσω File editor ή Samba.
5. Στην καρτέλα Ρυθμίσεις του add-on επικόλλησε όσα σου έδωσε το `make add-site`.
6. Έναρξη. Στην καρτέλα «Αρχείο καταγραφής» πρέπει να δεις:
   - `connected to Home Assistant`
   - `connected to MQTT broker`

## Ασφάλεια

- Το «Επιτρέπονται εντολές» είναι κλειστό από προεπιλογή. Όσο μένει κλειστό, το Villa OS
  μόνο βλέπει.
- Ακόμα και με τις εντολές ανοιχτές, εκτελούνται μόνο:
  - φώτα,
  - πρίζες,
  - κλιματιστικά.

  Επιπλέον, μόνο σε συσκευές που έχουν `allow_commands: true` στο αρχείο της βίλας.
  Κλειδαριές ποτέ.
- Μην ανοίξεις την αυτόματη ενημέρωση σε αυτό το add-on. Οι νέες εκδόσεις μπαίνουν
  μόνο όταν το αποφασίσεις εσύ.
