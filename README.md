# Villa OS: Villa Agent για Home Assistant

Στο Home Assistant: **Ρυθμίσεις → Apps → Κατάστημα → ⋮ → Repositories**, πρόσθεσε
`https://github.com/spicfu-crypto/villa-os-addon` και εγκατάστησε το **Villa Agent**.

Ο Villa Agent στέλνει στο Villa OS μόνο τις συσκευές που ορίζει το αρχείο της βίλας.
Δεν ανοίγει καμία θύρα στο σπίτι. Οι οδηγίες είναι στην καρτέλα «Τεκμηρίωση» του app.

Ο φάκελος `proxmox/` έχει τα scripts για να στηθεί ένα laptop με Proxmox ως server.
